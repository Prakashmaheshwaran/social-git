# Security policy

## Supported versions

Security fixes are applied to the current release line. Operators should run an
exact tagged release and follow the documented backup and manual upgrade
procedure.

## Reporting a vulnerability

Report vulnerabilities privately through the repository host's security
advisory channel. If that channel is unavailable, contact a maintainer through a
private channel before disclosing details publicly.

Do not include passwords, session cookies, CSRF values, API keys, personal data,
or live provider response captures in a report. A useful report includes the
affected release, deployment mode, impact, reproduction steps using synthetic
data, and any proposed remediation.

Please do not open a public issue until maintainers have acknowledged the report
and coordinated disclosure.
