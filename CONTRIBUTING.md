# Contributing to Social Git

Thank you for improving Social Git.

Before opening a change:

1. Keep platform access within the documented direct-session, fail-closed
   security boundaries.
2. Do not commit credentials, session material, personal data, generated
   databases, or provider response captures.
3. Run `npm run typecheck`, `npm test`, and `./scripts/test.sh`.
4. Update the generated OpenAPI and product documentation when their typed
   sources change.

Contributions to this repository are made under the same
[Apache-2.0 license](LICENSE) as the project. Third-party material must retain
its original license and attribution in the appropriate notice file.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md), not a public
issue.
